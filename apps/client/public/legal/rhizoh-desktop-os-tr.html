Rhizoh Masaüstü OS

Rhizoh web uygulamasını masaüstü kabuğu olarak kullanabilirsiniz. Arşiv ve kütüphane verileri cihazınızda kalır; EU AI Act uyumlu silinebilir kayıt kimlikleri ile olay günlüğü korunur.

Kurulum (PWA)

  1. rhizoh.com adresini Chrome veya Edge ile açın.
  2. Adres çubuğundaki Yükle / Install seçeneğini kullanın.
  3. Hukuki geçidi tamamlayın; tower workspace'lerde kendi API anahtarlarınızı bağlayın.

Arşiv ve kütüphane

Haritadaki Codex Vault veya capability halo Library ile belgelerinizi kaydedin; mediaplayer'a anında taşıyın.
