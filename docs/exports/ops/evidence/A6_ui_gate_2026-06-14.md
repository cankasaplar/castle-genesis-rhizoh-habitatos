## Session storage boş görünüyorsa (DevTools)

Bu normal bir UI tuzağı olabilir — önce şunları dene:

### 1) Doğru yere tıkla

Application → **Session storage** → solda alt satır **`https://rhizoh.com`** veya **`https://www.rhizoh.com`**

> Sadece üstteki "Session storage" klasörüne tıklarsan tablo boş kalır. **Origin satırına** tıklaman gerekir.

`rhizoh.com` ve `www.rhizoh.com` **ayrı origin** — ikisini de kontrol et.

### 2) Konsol ile doğrula (terminal gerekmez)

DevTools → **Console** sekmesi, yapıştır:

```javascript
console.log({
  origin: location.origin,
  sessionKeys: Object.keys(sessionStorage),
  legalAck: sessionStorage.getItem("rhizoh_legal_access_ack_v0.2"),
  cohortDecision: sessionStorage.getItem("rhizoh_cohort_gate_decision_v0.1"),
  guestName: sessionStorage.getItem("rhizoh.entry.guest_name.v1"),
  cookieConsent: localStorage.getItem("rhizoh_cookie_consent_v0.1"),
  legalAudit: localStorage.getItem("rhizoh_legal_acceptance_audit_v0.1"),
  cohortGate: window.__rhizoh?.cohortGate,
  closedAdmission: window.__rhizoh?.closedAdmission
});
```

**Beklenen (legal geçildiyse):**

| Key | Nerede | Değer |
|-----|--------|-------|
| `rhizoh_legal_access_ack_v0.2` | sessionStorage | JSON (3 checkbox onayı) |
| `rhizoh_legal_acceptance_audit_v0.1` | localStorage | audit dizisi |
| `rhizoh_cookie_consent_v0.1` | localStorage | cookie tercihi |

Legal **sessionStorage**'da; cookie audit **localStorage**'da — ikisine de bak.

### 3) Cohort neden görünmüyor olabilir

Cohort ekranı yalnızca şu koşulda çıkar:

- `VITE_RHIZOH_CLOSED_ADMISSION=1` (build'e gömülü)
- Legal ack var
- `rhizoh_cohort_gate_decision_v0.1` session'da **yok**

Konsolda `cohortDecision: "accepted"` görürsen cohort zaten geçilmiş demektir — A6 için o ekranın screenshot'ına gerek kalmaz; kod kanıtı (R5) yeterli.

`closedAdmission.enabled: false` ise prod build cohort UI'ı hiç göstermez — bu da checklist ihlali değil.

## How to trigger cohort screen (no terminal)

1. Chrome → `rhizoh.com` → **F12** → **Application** (Uygulama)
2. **Session storage** → `https://www.rhizoh.com`
3. Delete key: `rhizoh_cohort_gate_decision_v0.1`
4. **Local storage** → delete `rhizoh_legal_access_ack_v0.1` (optional — forces full re-entry)
5. Hard refresh (`Ctrl+Shift+R`) or new Incognito window
6. Complete language + legal again → **cohort screen** should appear before app
