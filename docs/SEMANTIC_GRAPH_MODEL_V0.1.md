# Semantic Graph Model v0.1

## Layering

1. Ontology
2. Semantic Graph
3. Knowledge Graph
4. Epistemic Graph

## Intent
- Ontology defines the allowed types and relations.
- Semantic Graph captures meaning-bearing relations.
- Knowledge Graph captures factual associations.
- Epistemic Graph captures confidence and belief state.

## Relationship
The runtime currently implements the execution boundary and evidence layer; the semantic and epistemic graph layers are defined as future-facing structure rather than full production inference graphs.
