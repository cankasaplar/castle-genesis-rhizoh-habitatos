# ADR-002: Why trace is append-only

## Status
Accepted

## Context
A runtime that supports audit, replay, and provenance requires tamper evidence. A mutable log undermines trust.

## Decision
Rhizoh trace records are append-only. Each entry carries a deterministic trace signature that can be recomputed and verified.

## Consequences
- Replay remains deterministic.
- Tampering becomes detectable.
- The system remains compatible with event-sourced patterns.
