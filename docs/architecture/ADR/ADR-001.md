# ADR-001: Why LLM has no commit authority

## Status
Accepted

## Context
The Rhizoh runtime needs a clear separation between explanation and execution. Language models can assist with interpretation, but they should not be allowed to make or approve state-changing actions directly.

## Decision
The runtime uses an LLM adapter only as a non-executive explanation layer. Execution authority remains with the deterministic runtime and its constitutional checks.

## Consequences
- Deterministic auditability is preserved.
- Explanations remain inspectable and replayable.
- The system avoids semantic authority creep.
