# ADR-003: Why ontology precedes planning

## Status
Accepted

## Context
Planning logic can be powerful, but it should never be allowed to bypass ontological impossibility.

## Decision
The runtime validates ontology constraints before planning and execution. If a proposal violates the ontology, it is rejected before execution proceeds.

## Consequences
- Impossible actions are rejected early.
- The runtime remains semantically constrained.
- Planning can work within a safe and explainable domain.
