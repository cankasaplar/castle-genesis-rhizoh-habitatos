## The real design failure (honest)

> *“Sayfayı açıp boş text görmek istemiyorum.”*

| Symptom | Meaning |
|---------|---------|
| Powerful but silent engine | User asks “what do I do?” |
| No tempo | No sense of **play in flow** |

**Basketball:** Even without a fast break, the game must **feel like it is moving**.

**Risk to avoid:** Not “too much intelligence” — **user never surfaces** (stuck below the waterline).

## T0 content model — Ready Flow, not Empty State

| Layer | Always / default | Pressure |
|-------|------------------|----------|
| **Map** | Visible (empty or seed-anchored) | Low — spatial world |
| **Chat input** | Active | Low — narrative thread |
| **Soft affordances** | 2–3 visible, non-dominant | Optional — user **binds**, does not “enable features” |

**Soft affordances (v0 copy):**

| Affordance | World | User action |
|------------|-------|-------------|
| Kale kur | Narrative (castle / memory) | Spawn / anchor personal castle |
| Anı ekle | Narrative | Add moment to continuity |
| Bağlan | Real-world binding | Event · sport · concert · world signal |

**System voice:** Does not ask *“What do you want to do?”* — conveys *“You can continue.”*

Features are **not hidden**; they are **not bossy**.

## Pedagogy — curiosity, not curriculum

Rhizoh does **not** run an onboarding tutorial. Coaching insight: players live the lesson without labeling it “learning.”

| Avoid | Prefer |
|-------|--------|
| “Learn the system” steps | **Merak ettir** — honest, fast, surprising growth |
| Performative “smart” UI | Dürüst zeka · gösterişsiz |
| Strict minimalism only | **Living pulse stream** for users who want flowing logs (aesthetic updates, seed commentary, interpreted signals) |

**Language:** User may speak any catalog locale — Rhizoh matches and bridges via similarity (e.g. English ↔ Spanish cognates) without forcing a single locale voice.

Code: `T0_CURIOSITY_PEDAGOGY_V0` · [`rhizohMultilingualBridgeV0.js`](../apps/client/src/rhizoh/runtime/rhizohMultilingualBridgeV0.js) · [`RHIZOH_MULTILINGUAL_BRIDGE_V0.md`](RHIZOH_MULTILINGUAL_BRIDGE_V0.md).

## Attention architecture (play-call clarity)

**Risk:** Everything visible + alive → **attention loss** (“where do I hold this?”).

**Success criterion (3 seconds):** User finds a **direction feeling** — not a feature list.

| Layer | Role |
|-------|------|
| **Context strip** | One line mental frame — e.g. `Keşif · Dünya açık`, `Üretim modu · Stüdyo hazır` |
| **Intent anchors** | Keşfet · Üret · İzle · Bağlan — session-persisted |
| **Surface breath** | World / Hall / Studio / … — navigation, not the only cue |
| **Pulse stream** | **Collapsed by default** — opt-in for log readers |

Code: [`t0ContextStripV0.js`](../apps/client/src/rhizoh/runtime/t0ContextStripV0.js) · fed by PAL + anchor + `activeSurface` + E2-X mode.

**State + intent:** Rhizoh is a **state-based environment**; context strip = visible **game rules** without tutorial chrome.
