## 1. What VCL is (and is not)

| ❌ Not | ✅ Is |
|--------|------|
| Decorative animation · hover polish | **Attention field representation** |
| Explaining UI | **Thinking surface** |
| Color-only feedback | **Geometry deformation** (color secondary) |
| Hover-local interaction | **Field-based global response** |

**Four simultaneous expression layers:**

| Layer | Role |
|-------|------|
| **System language** | Engine substrate — lattice, coherence |
| **Agent language** | Interpreting intelligence — lens overlay |
| **User language** | Input expression — distortion layer |
| **Shared evolution language** | What was learned — trace on surface, **not explained** |

## 2. Responsive Cognitive Field — design balance

| Pole | Risk | Target |
|------|------|--------|
| Too active | User becomes **spectator**; intelligence **performance** | Stimulating but not shouting |
| Too passive | **Black box** | Coherent deformation; every shift carries meaning |
| Coercive | Forced paths | **Directing without forcing** |

**Principles:** stimulating · coherent · non-coercive.

**Attention = field-based, not UI-based.**

## 3. VCL Core v0 (four operators)

| Operator | Behavior |
|----------|----------|
| **1. State deformation** | Intent / mode change → **geometry** shifts (facets, twist, breath) — not palette alone |
| **2. Cognitive tension field** | High salience → crystal **density** up; low priority → **dissolve** |
| **3. Agent lens overlay** | System = substrate · Agent = interpretation ripple · User = input distortion |
| **4. Shared evolution trace** | System leaves **what it learned** on the field — does not narrate it |
